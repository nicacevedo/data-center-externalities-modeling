## 1. Pipeline overview

The implemented pipeline reconstructs a **weather-driven facility** from **annual public campus totals**, then places those totals in **regional water and grid context**. It does **not** recover hourly IT telemetry, does **not** attribute Oregon generators to the campus, and does **not** run a groundwater or DID/causal model.

Layers actually executed:

1. **Targets.** `src/build_targets.py` curates Meta annual electricity (2011–2024), water withdrawal (2014–2024), location Scope 2, and operational GHG into `data/canonical/meta_prineville_annual.csv`.
2. **Weather.** NOAA Global Hourly KRDM → `data/processed/weather_hourly.csv`.
3. **Gray-box physics.** `src/prineville_graybox.py` maps IT power + weather → cooling mode, PUE, raw evaporation.
4. **Conditional reconstruction.** `src/conditional_reconstruction.py` closes annual facility electricity with one latent IT-power scale per year and predicts water with a train-only multiplicative scale on raw evaporation.
5. **Stochastic proxy.** `src/stochastic_conditional_simulation.py` is a **generative scenario** with a separate annual water **prediction** horse-race (energy-only selected).
6. **Context, not coupling.** OWRD City/POD, USGS HUC12 IWA/use, EIA-930 PACW, eGRID NWPP, Oregon CAMPD/EIA, DEQ backup, Crook County permits.

Annual electricity agreement is **closure, not prediction**. IWA `availab = strflow - consum` is an **identity, not hydrologic validation**. City production is **not** Meta delivery. Direct POD is **not** total Meta withdrawal.

## 4. Model quantity → source/proxy mapping

Full table: [`model_quantity_registry.csv`](../outputs/pipeline_report/model_quantity_registry.csv). Dependency diagram: [PNG](../outputs/pipeline_report/model_quantity_dependency.png).

Provenance classes used (exactly one per row): `reported / measured / derived / fitted / simulated / scenario / proxy / unavailable`.

### Workload arrivals (`A_{c,t}`)

- **What is it?** New work arriving in interval t. No public scheduler traces exist; the stochastic module draws scale-free Cox-process counts.
- **Where does it come from?** none (no telemetry); src/stochastic_conditional_simulation.py
- **How is it computed?** Poisson counts from diurnal/weekly/AR log-intensity; not recovered arrivals
- **Assumptions?** base_rate=72; mixed interactive/batch Cox scenario; scale-free by construction
- **Provenance:** `scenario` (implemented as generative scenario only)
- **Validation?** structural queue conservation only; no arrival telemetry
- **Confidence:** low (scenario, not observation). Hourly IT workload traces are not public.
### IT power (`P^{IT}_{i,t}`)

- **What is it?** Electricity used by IT equipment. Conditional reconstruction uses one latent constant-within-year IT-power scale so gray-box facility energy closes to reported annual facility MWh. Stochastic uses a workload shape then the same annual closure.
- **Where does it come from?** Meta annual facility electricity + NOAA weather + gray-box
- **How is it computed?** P_IT_scale = E_fac_reported / sum_t P_fac(weather, P_IT=1 MW); hourly P_IT = scale (conditional) or scale × shape (stochastic)
- **Assumptions?** constant IT power within a year in the conditional baseline; gray-box linear in IT power; not observed PDU telemetry
- **Provenance:** `fitted` (implemented as fitted latent (conditional) / simulated-then-closed (stochastic))
- **Validation?** annual electricity residual ≈ 0 by construction (outputs/conditional_annual_compare.csv)
- **Confidence:** low for hourly path; medium that annual IT energy is in a physically consistent PUE range. Hourly IT load is not public. Within-year variation is assumed (conditional) or scenario (stochastic).
### Facility electricity (annual reported) (`E^{fac}`)

- **What is it?** Meta-disclosed Prineville annual facility electricity. Hard observation for calibration.
- **Where does it come from?** META_2016_DISCLOSURE / META_2019_DISCLOSURE / META_2025_INDEX via build_targets.py
- **How is it computed?** avg MW = MWh / hours_in_year
- **Assumptions?** disclosed site annual total is the campus facility electricity used by the model
- **Provenance:** `reported` (implemented)
- **Validation?** source-vintage notes in meta_prineville_annual.csv
- **Confidence:** high as disclosed annual total. No monthly/hourly campus electricity observations.
### PUE (`PUE`)

- **What is it?** P_fac/P_IT from the gray-box. Annual modeled PUE ≈ 1.060. 2011 design full-load PUE 1.07 is a benchmark, not a fit target.
- **Where does it come from?** gray-box
- **How is it computed?** PUE = P_fac / P_IT
- **Assumptions?** bottom-up PUE; not an independent input
- **Provenance:** `derived` (implemented as derived KPI)
- **Validation?** 2011 modeled annual PUE 1.060 vs 1.07
- **Confidence:** medium vs 2011 design; low as a claim of true hourly PUE. No simultaneous IT and facility metering.
### Direct water consumption (`W^{dir,cons}`)

- **What is it?** Water not returned to the local system. Not identified: no discharge/sewer series and Meta tables used here are withdrawal.
- **Where does it come from?** not identified
- **How is it computed?** would require withdrawal minus discharge or a documented consumptive fraction; neither is in code
- **Assumptions?** n/a
- **Provenance:** `unavailable` (unavailable)
- **Validation?** none
- **Confidence:** none. Site consumption is not publicly reported as a separate campus series in the canonical table.
### Direct water withdrawal (Meta annual) (`W^{dir,with}`)

- **What is it?** Meta-disclosed Prineville annual water withdrawal. Hard observation. Not monthly.
- **Where does it come from?** META_2016_DISCLOSURE / META_2019_DISCLOSURE / META_2025_INDEX

## 6. Core equations and assumptions

### Gray-box (`src/prineville_graybox.py`)

Assumed parameters (code priors, **not reported Meta facts** except the 2011 technology class):

- `supply_target_C = 25`
- `return_air_C = 35` (**declared but unused** in `simulate()`)
- `evap_effectiveness = 0.85`
- `server_deltaT_C = 12`
- `dry_air_cp_J_kgK = 1006`
- `fan_fraction_of_it = 0.025`
- `other_facility_fraction_of_it = 0.035`
- evaporative auxiliary `0.005 × P_IT × spray`

Equations actually coded:

1. **IT heat / airflow:** \(m_\mathrm{air} = P^{IT} \times 10^6 / (c_p \Delta T_\mathrm{server})\).
2. **Full-evap outlet:** \(T_\mathrm{full} = T_{db} - \varepsilon \max(T_{db}-T_{wb},0)\).
3. **Supply:** outdoor if \(T_{db} \le 25\); else 25 °C if reachable; else \(T_\mathrm{full}\).
4. **Evaporative water:** humidity-ratio increase at constant moist-air enthalpy; \(\mathrm{m}^3/\mathrm{h} = (\mathrm{kg/s}) \times 3.6\).
5. **Facility power:** \(P_\mathrm{fac} = P^{IT} + 0.025 P^{IT} + 0.035 P^{IT} + 0.005 P^{IT} \mathrm{spray}\).
6. **PUE:** \(P_\mathrm{fac} / P^{IT}\).
7. **Modes:** `outside_air_or_winter_mix` / `partial_evap` / `full_evap`.

2011 design benchmark used only as a **falsification diagnostic**: full-load PUE 1.07, WUE 0.31 L/kWh. Current modeled 2011 annual PUE = **1.0601**.

### Conditional reconstruction

1. Annual electricity **closure** via one latent IT-power scale (linear gray-box).
2. Weather-driven hourly gray-box **shape**.
3. Water **raw-evaporation proxy**.
4. Global vs one-break multiplicative water scale; **global selected** (\(s=6.580051\), BIC=-15.38).
5. Log-scale fitting (geometric mean).
6. BIC with a required improvement of 2 to prefer one-break (3 parameters).
7. Training through 2022; **2023–2024 holdout**.

### Annual water prediction candidates (stochastic workflow)

Pre-registered nonnegative no-intercept models, expanding-window one-step MAPE on train, then freeze:

- energy-only (**selected**, \(\beta_E \approx 0.3643\,\mathrm{m}^3/\mathrm{MWh}\), rolling MAPE 34.25%)
- evaporation-only (not selected)
- energy + evaporation NNLS (evaporation coefficient currently 0; still not selected)

### Stochastic proxy

Cox-process arrivals, AR latent intensity, Poisson counts, Gamma work sizes, aggregate queue, utilization → IT-power shape, annual facility-energy scaling, uncertain facility-overhead priors, retrospective water-shape mixture, scenario ensemble (seed 20260812, 32 sims/year, `mixed_cox`). This is **not** recovered workload telemetry.

### Carbon

- Meta annual **reported location Scope 2**.
- **eGRID NWPP × Meta MWh** independent physical benchmark.
- **PACW EIA consumed CO2** as regional hourly **relative shape** (optional).
- Fuel/import score: **sensitivity proxy only**.
- None of these is a Meta-specific marginal-emissions model.

### Change-point screening

`src/change_point_seed.py` ranks piecewise-linear SSE reductions. Statistical candidates only (train-only water/intensity peak at 2020). Not a physical technology-change claim.

## Documentation vs executable code

If documentation disagrees with code, **code behavior wins**. Current discrepancies:

- **source_manifest.csv completeness.** Documentation: data/source_manifest.csv lists 34 sources (Meta, OWRD, NOAA, EIA-930, eGRID, USGS, OHA, City, ASR PDFs). Code/files: Executable pipeline also uses data/raw/{campd,eia860,eia923,eia_cooling,epa_eia_crosswalk,deq_air,deq_ghg} and Crook County permit tables. Resolution: Inventory includes those sources. Manifest is incomplete relative to code.
- **NOAA_GH_KRDM_FILES bundling.** Documentation: source_manifest status says Global Hourly files are not bundled because remote CSV access may be environment-dependent. Code/files: data/processed/weather_hourly.csv exists for 2011-2024 and is required by reconstruction. Resolution: Processed weather is the executable input. Raw yearly CSVs may or may not be present under data/raw/noaa/.
- **NOAA_ISD station-ID verification.** Documentation: source_manifest NOAA_ISD status still says station-ID verification is needed. Code/files: config/prineville.yaml and download_noaa_global_hourly.py use KRDM 72692024230. Resolution: Code uses KRDM. Manifest status is stale.
- **a2 WUE curves in glossary.** Documentation: modeling/glossary_mapping.tex defines Gupta et al. fixed-approach/fixed-cold-water WUE curves. Code/files: src/prineville_graybox.py implements air-side evaporative humidification, not those polynomials. Resolution: Quantity Q_A2_WUE is unavailable. Implemented water physics is the gray-box.
- **return_air_C prior.** Documentation: Params.return_air_C = 35.0 is declared in prineville_graybox.py. Code/files: simulate() never reads return_air_C. Resolution: Documented as unused in the quantity registry and gray-box model notes.
- **README Stage 8 validation hierarchy.** Documentation: README.md Stage 8 lists 'annual held-out electricity/water/location-Scope-2 prediction'. Code/files: src/conditional_reconstruction.py closes electricity every year; location Scope 2 is closed in the stochastic proxy; only water has a chronological holdout prediction. Resolution: Electricity and Scope 2 agreement are closure. Water 2023-2024 errors are the predictive holdout. Report command documents this; README Stage 8 item 3 should not be read as electricity forecast skill.

## Reproducibility

```bash
python run_prineville.py report
```

The command uses existing processed data only, does not download, and fails if prerequisites are missing. It is deterministic (figure 6 week selection is a documented argmax; seed 20260812 is recorded even though this report draws no new stochastic ensemble).
